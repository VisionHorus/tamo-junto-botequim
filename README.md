# Tamo Junto Botequim

Site institucional e cardápio digital do Tamo Junto Botequim, em Salvador - BA.

O projeto reúne informações institucionais, cardápio, unidades, meios de contato e informações úteis para clientes.

## Objetivo do projeto

O site foi desenvolvido para permitir que clientes possam:

- conhecer o Tamo Junto Botequim;
- consultar o cardápio;
- escolher uma unidade;
- consultar endereço e horário;
- encontrar os canais de contato;
- acessar WhatsApp e rotas;
- conhecer a história e a proposta da marca.

O projeto também é estruturado para boas práticas de:

- SEO técnico;
- SEO local;
- acessibilidade;
- performance;
- experiência do usuário;
- dados estruturados;
- rastreamento por mecanismos de busca.
